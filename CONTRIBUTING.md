# Contributing to NoteMind

Thanks for your interest! NoteMind takes part in **Hacktoberfest**.

## How to contribute
1. Fork the repo and create a branch: `git checkout -b feature/my-idea`
2. Run locally: `python3 -m http.server 8000`, then open http://localhost:8000 in Chrome/Edge 113+.
3. Keep changes small and focused, and test them in the browser.
4. Commit with a clear message and open a Pull Request describing what you changed and why.

## Good first issues
- Export the quiz or key terms as flashcards (CSV/Anki)
- Add a model selector (e.g. larger Qwen2.5 or Gemma builds)
- Hindi/multilingual output option
- Dark mode and better mobile layout

## Rules
- Be respectful; follow the [MLH Code of Conduct](https://github.com/MLH/mlh-policies/blob/main/code-of-conduct.md).
- Spam or low-effort PRs will be marked invalid.
- By contributing you agree your code is released under the MIT License.
